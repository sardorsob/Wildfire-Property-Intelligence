# Project core

- Capstone goal: identify possible reporting inconsistencies in aggregated California NSI property attributes for wildfire-risk applications.
- Durable surfaces: notebooks and saved evidence, report sources/PDFs, static React site, and archived export backend.
- Source map: `dataset/`; `notebooks/`; `results/tables/`; `figures/`; `report/`; `scripts/`; `website/frontend/`; `website/_archive/backend/`.
- The notebook collection is staged research, not a normalized serial runner. Read `mem:notebooks/core` for the workflow and its path caveats.
- Frontend JSON under `website/frontend/public/data/` is checked in; it is generated by notebook results or archived exports, not edited by hand. Read `mem:frontend/core` for the site contract.
- Read `mem:tech_stack`, `mem:conventions`, and `mem:task_completion` for maintenance constraints.
